# THERMOMETER WIDGETS

A reusable Tkinter thermometer class demonstrated with two independent panels.

[GitHub](https://github.com/MOHAMMADREZAABEDINPOOR/thermometer) · [PIMX / Profile](https://github.com/MOHAMMADREZAABEDINPOOR) · [Static artwork](assets/readme/hero.png)

## Features

- Reusable th class
- Spinbox temperature selection
- Colored column visualization

## Stack

| Tool | Version / source |
|---|---|
| Python | `standard library / source imports` |

## Getting started

Python 3; a desktop/Tk installation for Tkinter or turtle examples. Tkinter is provided by the Python installation, not pip. Legacy dependencies may need a compatible Python version.

```bash
git clone https://github.com/MOHAMMADREZAABEDINPOOR/thermometer.git
cd thermometer

python "thermometer1.py"
```

## Configuration

No standard environment template is defined. Standalone exercises need no external configuration; inspect any service constants or paths in the source before running.

## Usage

Run thermometer1.py; each panel has its own temperature spinbox.
